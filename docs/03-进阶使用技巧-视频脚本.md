# 进阶使用技巧 — 视频脚本

## 基本信息

- 时长：约 3 分钟（4 个技巧，每个约 45 秒）
- 风格：温暖、深度、有洞察
- 背景音乐：叙事感钢琴

---

## 口播稿全文

---

"用了一段时间望杏成林，这几个技巧让我的记录更有价值。

**第一个：记录怎么写更好。**

孩子的原话是最好的素材。比如孩子早餐时说，妈妈你每天做饭很辛苦，我以后帮你擦桌子——这句话记下来，比说孩子很懂事有价值一万倍。

记录孩子的情绪反应也很重要。比如他输了比赛假装不在乎，但我看见他红了眼眶——这样的观察，AI 能读出孩子正在学习处理挫败感。

记住，不要写评价，写事件。'孩子今天不听话'是评价，'孩子拒绝穿我准备的衣服，自己选了一件'才是值得记录的事件。

**第二个：怎么看懂机会窗口。**

机会窗口是孩子当前最需要被支持的方向，不是问题。

当 AI 说建设性是机会窗口，意思是孩子正在学习面对困难。这时你可以做的是：先确认不急着给方法，问孩子你觉得怎么办，而不是你应该怎么做。允许失败，这个方向正是孩子还在练习的。

关注过程不看结果。你可以说，你坚持尝试了三次，这个过程很有价值——而不是说，你怎么不知道放弃。

**第三个：滋养时刻怎么用。**

滋养时刻是亲子彼此滋养的瞬间，分四个层次：

第一层，彼此连接，一个拥抱一句晚安。

第二层，彼此看见和懂得，孩子说妈妈懂我。

第三层，彼此理解，理解行为背后的心理需求。

第四层，彼此支持，困难时互相陪伴。

日常小互动多属于第一层，深度陪伴中会出现更深层次。

用滋养时刻做什么呢？回看时给自己力量，困难时翻一翻，重新看见你们之间那些真实存在过的温暖。

**第四个：综合报告重点看什么。**

反复出现的方向——几次记录都提到同一个词，这是孩子的发展主线。

变化和成长——和上周比，孩子在哪个方向有了进步。

机会窗口的演化——上个月是自主，这个月变成建设性，说明孩子在成长。

记住，坚持比技巧重要。设一个每天的提醒，睡前十分钟，回想今天和孩子发生了什么，记下来。

看见孩子，看见自己。"

```
温暖治愈、叙事感，竖屏 9:16，
以人物出镜讲述为主，
穿插手机 App 界面截图展示记录操作，
字幕随语音同步出现，
轻缓钢琴背景音乐，
不要动画感，不要卡通风格
```
