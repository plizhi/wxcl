## 一、问题分析

### 现状
- 机会窗口（P0-1）会被追踪
- 但连续多次出现的方向，没有主动提醒家长的机制
- 用户需要自己去查看才能发现"这个方向一直在出现"

### 理想状态
- 当某个机会窗口连续出现3次以上，自动触发预警提醒
- 用温和的方式提醒家长："这个方向最近出现多次了"
- 不强迫，只是善意提示

## 二、方案设计

### 2.1 预警等级

```typescript
const WARNING_LEVELS = {
  // 关注级（出现2次）
  ATTENTION: {
    level: 1,
    threshold: 2,
    title: '💡 关注提醒',
    message: '「{dimension}」这个方向最近出现了，值得留意一下',
    color: 'yellow',
    autoNotify: false,  // 不主动推送，只在页面显示
  },
  
  // 警告级（出现3次）
  WARNING: {
    level: 2,
    threshold: 3,
    title: '⚠️ 温和提示',
    message: '「{dimension}」这个方向已经连续出现了3次，可以留意一下哦',
    color: 'orange',
    autoNotify: true,  // 可以推送提醒
  },
  
  // 严重级（出现5次）
  SERIOUS: {
    level: 3,
    threshold: 5,
    title: '🔴 关注提醒',
    message: '「{dimension}」这个方向一直出现，建议深入了解一下',
    color: 'red',
    autoNotify: true,
    priority: 'high',
  },
};
```

### 2.2 预警触发机制

```typescript
// 在机会窗口更新时计算预警等级
async function calculateWarningLevel(opportunity: Opportunity): Promise<number> {
  const count = opportunity.appearance_count;
  
  if (count >= 5) return 3;  // 严重
  if (count >= 3) return 2;  // 警告
  if (count >= 2) return 1;  // 关注
  return 0;
}

// 预警变化时，发送通知
async function checkAndNotifyWarningChange(
  opportunity: Opportunity, 
  newLevel: number
) {
  if (newLevel <= opportunity.warning_level) return;  // 没有升级，不处理
  
  const config = Object.values(WARNING_LEVELS).find(w => w.level === newLevel);
  if (!config || !config.autoNotify) return;
  
  // 发送通知
  await sendNotification({
    type: 'opportunity_warning',
    childId: opportunity.child_id,
    title: config.title,
    content: config.message.replace('{dimension}', opportunity.dimension),
    priority: config.priority || 'normal',
    data: {
      opportunityId: opportunity.id,
      dimension: opportunity.dimension,
    },
  });
}
```

## 四、数据库设计

```sql
-- 预警通知表（新增）
CREATE TABLE IF NOT EXISTS opportunity_notifications (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  child_id UUID NOT NULL REFERENCES children(id) ON DELETE CASCADE,
  opportunity_id UUID NOT NULL REFERENCES profile_opportunities(id) ON DELETE CASCADE,
  
  level INT NOT NULL,                    -- 预警等级 1/2/3
  title VARCHAR(50),                    -- 通知标题
  message TEXT,                          -- 通知内容
  status VARCHAR(20) DEFAULT 'pending',  -- pending/sent/read/dismissed
  sent_at TIMESTAMP,                     -- 发送时间
  read_at TIMESTAMP,                     -- 阅读时间
  
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_notifications_child ON opportunity_notifications(child_id);
CREATE INDEX IF NOT EXISTS idx_notifications_status ON opportunity_notifications(status);
```

### 6.2 预警详情弹窗

```tsx
// src/components/opportunity-warning-modal.tsx

interface OpportunityWarningModalProps {
  visible: boolean;
  onClose: () => void;
  warning: OpportunityWarning | null;
  onAcknowledge: (id: string) => void;
  onDismiss: (id: string) => void;
}

function OpportunityWarningModal({ 
  visible, 
  onClose, 
  warning, 
  onAcknowledge,
  onDismiss 
}: OpportunityWarningModalProps) {
  if (!warning) return null;
  
  return (
    <Modal visible={visible} onClose={onClose}>
      <div className="p-4">
        <div className="text-center mb-4">
          <span className="text-4xl">
            {warning.level === 3 ? '🔴' : warning.level === 2 ? '⚠️' : '💡'}
          </span>
        </div>
        
        <h3 className="text-lg font-medium text-center mb-2">
          {warning.title}
        </h3>
        
        <p className="text-sm text-gray-600 text-center mb-4">
          {warning.message}
        </p>
        
        {/* 出现历程 */}
        <div className="bg-gray-50 rounded-xl p-3 mb-4">
          <p className="text-xs text-gray-500 mb-2">出现历程</p>
          <div className="space-y-1">
            {warning.appearances?.map((a, i) => (
              <div key={i} className="text-xs text-gray-600 flex items-center gap-2">
                <span className="w-2 h-2 rounded-full bg-orange-400" />
                <span>{a.date}</span>
                <span className="text-gray-400">-</span>
                <span>{a.description}</span>
              </div>
            ))}
          </div>
        </div>
        
        {/* 操作 */}
        <div className="flex gap-2">
          <button
            onClick={() => onDismiss(warning.id)}
            className="flex-1 py-2 border rounded-full text-gray-500 text-sm"
          >
            忽略
          </button>
          <button
            onClick={() => onAcknowledge(warning.id)}
            className="flex-1 py-2 bg-orange-500 text-white rounded-full text-sm"
          >
            我知道了
          </button>
        </div>
      </div>
    </Modal>
  );
}
```
