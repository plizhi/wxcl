## 一、问题分析

### 现状
- 每次生成报告，AI 会从六要素视角分析出 1-2 个"机会窗口"
- 但这些机会窗口只是单向输出，没有被记录和追踪
- 下次再生成报告时，AI 并不"记得"之前提过哪些机会窗口

### 理想状态
- 系统记住每个被提及的机会窗口
- 每次新记录提交时，AI 会先看看"历史上关注过哪些方向"
- 在回复中自然地回溯："上周我们提到了XXX，这周呢？"
- 连续多次出现的方向，会触发更深入的洞察

### 2.3 相似窗口匹配逻辑

```typescript
// 匹配规则：同维度 + 描述相似度 > 60%
function isSimilarOpportunity(
  existing: Opportunity, 
  newOne: { dimension: string; description: string }
): boolean {
  // 1. 同维度
  if (existing.dimension !== newOne.dimension) return false;
  
  // 2. 描述相似度检查（简单实现：关键词重叠）
  const existingWords = existing.description.split('').filter(Boolean);
  const newWords = newOne.description.split('').filter(Boolean);
  const overlap = existingWords.filter(w => newWords.includes(w)).length;
  const similarity = overlap / Math.max(existingWords.length, newWords.length);
  
  return similarity > 0.6;
}
```

### 3.2 改造 analyze API

```typescript
// 在 src/app/api/daily-care/analyze/route.ts 中增加：

// 1. 分析完成后，保存机会窗口
async function processOpportunities(
  childId: string, 
  report: AnalyzeReport, 
  recordId: string
) {
  const opportunities = [report.opportunity_axis1, report.opportunity_axis2]
    .filter(Boolean);
  
  for (const opp of opportunities) {
    // 查询是否有相似窗口
    const existing = await findSimilarOpportunity(childId, opp);
    
    if (existing) {
      // 更新已有窗口
      await updateOpportunity(existing.id, {
        last_appeared_at: new Date(),
        appearance_count: existing.appearance_count + 1,
        warning_level: calculateWarningLevel(existing.appearance_count + 1),
      });
    } else {
      // 创建新窗口
      await createOpportunity({
        child_id: childId,
        dimension: opp.dimension || opp.element,
        description: opp.description,
        suggestion: opp.suggestion,
        source_record_id: recordId,
        first_appeared_at: new Date(),
        last_appeared_at: new Date(),
        status: 'open',
      });
    }
  }
}

// 2. 在回复生成前，注入历史上下文
async function buildOpportunityContext(childId: string): Promise<string> {
  const openOpportunities = await query(
    `SELECT dimension, description, appearance_count, last_appeared_at
     FROM profile_opportunities 
     WHERE child_id = $1 AND status = 'open'
     ORDER BY appearance_count DESC, last_appeared_at DESC
     LIMIT 3`,
    [childId]
  );
  
  if (openOpportunities.length === 0) return '';
  
  return OPPORTUNITY_CONTEXT_PROMPT.replace(
    '{openOpportunities}',
    openOpportunities.map((o, i) => ({
      name: '孩子', // 实际应从孩子表查姓名
      dimension: o.dimension,
      description: o.description,
      appearance_count: o.appearance_count,
      last_appeared_at: formatRelativeTime(o.last_appeared_at),
    }))
  );
}
```

## 五、预警机制

```typescript
function calculateWarningLevel(appearanceCount: number): number {
  if (appearanceCount >= 5) return 3;  // 严重
  if (appearanceCount >= 3) return 2;  // 警告
  if (appearanceCount >= 2) return 1;  // 关注
  return 0;
}

// warning_level 变化时，推送通知
async function checkWarningLevelChange(
  opportunity: Opportunity, 
  newLevel: number
) {
  if (newLevel >= 2 && opportunity.warning_level < 2) {
    // 触发预警通知
    await sendNotification({
      type: 'opportunity_warning',
      childId: opportunity.child_id,
      title: '💡 关注提醒',
      content: `「${opportunity.description}」这个方向最近出现较多次，可以考虑多留意一下哦。`,
      priority: newLevel === 3 ? 'high' : 'normal',
    });
  }
}
```
